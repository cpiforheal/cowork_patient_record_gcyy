前台打印代理（本机版）

用途
本文件夹必须放在“实际连接打印机的前台电脑”上运行。它只监听该电脑本机的 127.0.0.1:18848，不开放给局域网其他电脑。

启动方法
1. 将整个 frontdesk-print-agent 文件夹复制到前台电脑，例如桌面或 D 盘。
2. 双击“启动前台打印代理.cmd”。首次运行时如 Windows 询问是否允许 PowerShell 运行，请允许。
3. 保持打开的 PowerShell 窗口不要关闭；关闭窗口即停止打印代理。
4. 在前台电脑浏览器中访问 http://127.0.0.1:18848/health，看到 JSON 状态即说明代理已启动。
5. 回到门诊系统，在打印设置中选择前台电脑已安装的打印机，并将当前终端绑定为前台终端。

常见问题
- 页面提示“打印服务不可用”：先确认本机健康检查地址能打开，再按 Ctrl+F5 强制刷新门诊系统页面。
- 看不到打印机：先在 Windows“设置 > 蓝牙和设备 > 打印机和扫描仪”确认该打印机能正常打印测试页。
- 每次重启电脑后需要重新双击启动。确认稳定后，可由管理员把该启动文件加入 Windows 开机启动项。

注意
部署服务器上启动 18848 不能替代前台电脑的代理；浏览器只能安全地调用当前前台电脑本机的打印代理。
