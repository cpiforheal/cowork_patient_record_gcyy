# 叫号大屏部署与运维指南

> 适用：门诊候诊大屏（检查/接诊）与中药房取药大屏
> 更新：2026-07-26

## 一、设备要求

| 项目 | 要求 |
|---|---|
| 播放主机 | 可运行 Chrome/Edge 最新稳定版的电脑、迷你主机或安卓盒子 |
| 显示设备 | 1080p 及以上电视或显示器（HDMI 接播放主机） |
| 声音 | 有源音箱或电视自带扬声器（叫号只需扬声器，不需要麦克风） |
| 网络 | 有线内网优先，可访问业务主机 `http://<业务主机IP>:18849/` |

## 二、展示账号（一次性配置）

大屏使用专用「展示终端」账号，**30 天长效会话 + 自动滑动续期**：只要大屏在正常轮询，会话就不会过期；普通岗位账号仍为 12 小时。

1. 管理员登录系统 → 系统管理 → 账号管理 → 新建账号：
   - 岗位角色选择 **展示终端**；
   - 关联任意一个启用科室（如门诊）；
   - 初始密码首次登录时会强制修改，请修改后妥善保管。
2. 该账号仅能访问两块大屏页面，无法进入任何业务工作台；调用业务接口会被拒绝（403）。
3. 在播放主机浏览器上用该账号登录一次即可，登录后会自动进入大屏页面。

大屏地址（登录后）：

```text
门诊候诊大屏：http://<业务主机IP>:18849/#/tcm-pharmacy/clinic-queue/display
中药房取药大屏：http://<业务主机IP>:18849/#/tcm-pharmacy/display
深色主题（可选）：在地址后追加 ?theme=dark ，例如 .../display?theme=dark
```

## 三、开机自启与语音自动播放（kiosk 模式）

浏览器默认禁止页面自动发声，必须用以下启动参数绕过，否则每次重启都需人工点击"开启语音"。

在播放主机创建开机启动脚本（Windows 示例，放入 `shell:startup` 启动目录）：

```bat
@echo off
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" ^
  --kiosk "http://<业务主机IP>:18849/#/tcm-pharmacy/clinic-queue/display" ^
  --autoplay-policy=no-user-gesture-required ^
  --disable-session-crashed-bubble --noerrdialogs --disable-infobars
```

Edge 将路径换成 `msedge.exe`，参数相同。要点：

- `--kiosk`：无边框全屏，观众看不到浏览器界面；
- `--autoplay-policy=no-user-gesture-required`：允许语音自动播放；
- 大屏页面本身也会在加载时静默尝试解锁音频，解锁状态在本机持久保存；若仍被浏览器拦截，屏幕右上角会出现"开启语音"按钮，人工点击一次即可。

## 四、日常运行行为说明

- 数据每 5 秒自动刷新（后端可调）；网络抖动时自动退避重试，恢复后自动追上。
- 断网/后端不可用：顶部出现红色提示条；超过 1 分钟整屏出现"数据更新中断，请以现场叫号为准"遮罩；超过 10 分钟页面自动整体重载尝试自愈。
- 会话失效（如管理员重置了展示账号密码）：屏幕显示"大屏会话已失效"引导页，需要用展示账号重新登录一次，不会自动跳回普通登录页。
- 时钟以业务主机服务器时间为准，不受播放主机本机时钟漂移影响。
- 叫号语音：豆包 TTS 优先，不可用时自动降级为浏览器本地语音合成；每条播报朗读两遍。

## 五、故障排查

| 现象 | 处置 |
|---|---|
| 有弹窗无声音 | ①确认音箱电源/音量；②看右上角语音 chip 是否为"开启语音"待点击态；③确认启动脚本包含 `--autoplay-policy=no-user-gesture-required` 后重启浏览器 |
| 屏幕显示"大屏会话已失效" | 用展示终端账号重新登录一次（密码由管理员保管）；若频繁出现，检查是否有人重置了该账号密码（重置会吊销旧会话） |
| 顶部红条"连接中断" | 检查播放主机网线/内网连通性，`ping <业务主机IP>`；后端服务是否在运行（业务主机 `http://localhost:18081/health`） |
| 屏幕内容长时间不变但无红条 | 查看页脚"最后更新"时间；超过 10 分钟系统会自动重载，如未重载可手动按 F5 |
| 语音报错乱/重复 | 同一浏览器不要同时开多个相同大屏标签页；跨设备多屏各自独立播报属正常设计 |
| 开机后停在桌面未进大屏 | 检查启动目录脚本是否存在、浏览器路径是否正确 |
